# FirstProject

Portafolio web personal desarrollado como proyecto inicial utilizando tecnologías básicas de desarrollo frontend.

## 📌 Descripción

FirstProject es una página web sencilla tipo portafolio donde se presenta información personal, habilidades tecnológicas y enlaces de navegación.

El objetivo principal del proyecto es practicar:

- Estructura HTML
- Estilos básicos con CSS
- Organización de contenido web
- Uso de Git y GitHub

## 🖼️ Vista previa

La página incluye:

- Barra de navegación
- Presentación personal
- Lista de habilidades
- Tecnologías utilizadas
- Canción favorita con enlace externo
- Footer informativo

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
